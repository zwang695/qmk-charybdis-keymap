# Zachary keymap

Six-layer Charybdis 4x6 port of the existing Voyager layout. It includes
home-row modifier behavior, macOS shortcuts, Charybdis trackball controls,
caps word, layer lock, and Getreuer's `select_word` module.

Hold the furthest left-half thumb key for the mouse layer. On that layer, `F`
and `D` are left and right click, while `S` and `A` increase and decrease the
trackball CPI. Hold the empty right-half thumb key for drag-scroll.
